How to import

Send a POST with your key in the X-API-Key header.

Endpoint
POST /api/skill-import/skills
Example (curl)
curl -X POST {{ request.base_url }}api/skill-import/skills \
  -H "X-API-Key: <your-key>" \
  -H "Content-Type: application/json" \
  -d '{
  "agent_alias": "{{ example_alias }}",
  "skills": [
    {
      "name": "Refund policy",
      "description": "How to handle refund requests",
      "content": "# Refunds\n...markdown body...",
      "tags": "support,billing",
      "status": "enabled"
    }
  ]
}'
agent_alias
Required. Alias of the target agent.
name
Required per skill. Matches by name → update, else create.
description
Optional short summary.
content
Optional markdown body of the skill.
tags
Optional comma-separated tags.
status
Optional: enabled (default) or disabled.
